# SAGA IT TYPE PARTY

[SAGA IT COMMUNITY DAY 2027](https://furukawa3152.github.io/saga-it-community-day2027/) で遊ぶ、プログラミング用語のタイピング。コミュニティ名と名前を入れて、20語句を打ち切るまでの速さでコミュニティの順位が決まる。

いま動くのはローカル実行まで。公開先の Vercel と、そこに置く共有データベースはまだ入っていない。

## 遊び方

1. コミュニティ名と名前を入れる。以前に入力されたコミュニティは、ボタンから選べる
2. カウントが終わると計測が始まる
3. 画面のローマ字を、表示どおりに打つ
4. 20語句を打ち切ると、経過時間と順位が保存される

途中で `Esc` を押すと登録画面に戻る。そのプレイは記録されない。コミュニティ名だけは、挑戦を始めた時点で候補に残る。

## 順位

コミュニティの順位は、その中で一番速い人の自己ベスト。表示の数字もそのタイム。速い方が上。

個人の一覧は、参加者ごとの自己ベスト。同じ表記のゆれ（大文字小文字や余分な空白）は、同じコミュニティ・同じ人として扱う。

## 打ち方

入力判定は、家族向けタイピングのローマ字ルールを移している。

- 「ん」は `n` でも `nn` でも打てる
- 「し」は `shi` でも `si` でも打てる。ほかのゆれ表記も同様
- 長音の「ー」はハイフン
- 空白はスペース

お題は65語句から、毎ラウンド20個を無作為に出す。

## 動かし方

Node.js 22 以降。SQLite は Node 組み込みの `node:sqlite` を使う。

```bash
pnpm install
pnpm dev
```

ブラウザで http://localhost:3000 を開く。

```bash
pnpm test
pnpm typecheck
```

## 記録

完了したプレイと、入力されたコミュニティ名は `data/party.sqlite` に保存する。このファイルは Git に含めない。同じマシンでサーバを動かしているブラウザ同士は、この記録を共有する。

| 経路 | 内容 |
| --- | --- |
| `GET /api/rankings` | コミュニティ順位と個人の自己ベスト |
| `POST /api/runs` | 20語句を打ち切った記録 |
| `GET /api/communities` | 選択できるコミュニティ名 |
| `POST /api/communities` | 挑戦開始時にコミュニティ名を残す |
