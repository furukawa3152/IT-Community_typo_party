# SAGA IT TYPE PARTY

[SAGA IT COMMUNITY DAY 2027](https://furukawa3152.github.io/saga-it-community-day2027/) で遊ぶ、IT の英単語と1行コードのタイピング。コミュニティ名と名前を入れて、決められた問題数（既定は20問）を打ち切るまでの速さでコミュニティの順位が決まる。

`DATABASE_URL` があれば記録は Neon Postgres に入る。未設定のローカル実行は、このマシンの SQLite に入る。

## 遊び方

1. コミュニティ名と名前を入れる。以前に入力されたコミュニティは、ボタンから選べる
2. カウントが終わると計測が始まる
3. 画面の英単語やコードを、表示どおりに打つ
4. 全問を打ち切ると、経過時間と順位が保存される

途中で `Esc` を押すと登録画面に戻る。そのプレイは記録されない。コミュニティ名だけは、挑戦を始めた時点で候補に残る。

## 順位

コミュニティの順位は、その中で一番速い人の自己ベスト。表示の数字もそのタイム。速い方が上。

順位に使うのは、いま設定されている問題数で打ち切った記録だけ。ほかの問題数の記録は残っていて、設定を戻すとまた順位に出る。

個人の一覧は、参加者ごとの自己ベスト。同じ表記のゆれ（大文字小文字や余分な空白）は、同じコミュニティ・同じ人として扱う。

## 打ち方

どのお題も、表示された文字を1文字ずつ照合する。

- 用語は小文字の英単語。見出しに日本語の意味が出る。大文字で打っても通る
- 2語の用語（`pull request` など）の空白はスペース
- コードは書いてあるとおりに打つ。記号も大文字小文字もそのまま照合する

日本語入力はオフにしておく。

## お題

問題数は設定画面で 5〜50問 に変えられる。どの問題数でも、用語とコードは 12:8、コードのうち Python と HTML は 3:2:残り の比率で引く。既定の20問の内訳は次のとおり。

| 種類 | 数 | 中身 |
| --- | --- | --- |
| 用語 | 12 | IT の英単語60語から無作為 |
| コード | 8 | Python 3行、HTML 2行、残り3行は JavaScript・CSS・SQL・シェルも含めて無作為 |

コードはすべて改行なしの1行。お題は `lib/words.ts` の `TERMS` と `CODES`、内訳は `lib/round.ts` の `planRound` にある。

## 設定画面

入口の下の「設定」から http://localhost:3000/settings を開く。

- **競う問題数**: 5〜50問。保存すると、次に始める挑戦から反映される
- **データベースの初期化**: すべての記録とコミュニティ名を消す。「初期化」と打ってからボタンを押す。問題数の設定は残る

操作には `ADMIN_PASSWORD` が要る。ローカルで空のときはパスワードなしで使える。公開先（Vercel）で空のままだと、設定画面は誰も操作できない。バックスラッシュとバッククォートは JIS 配列の Mac で打ちにくいので使わない。

## 動かし方

Node.js 22 以降。SQLite は Node 組み込みの `node:sqlite` を使う。

```bash
pnpm install
pnpm dev
```

ブラウザで http://localhost:3000 を開く。

```bash
pnpm test
pnpm typecheck
```

## 記録

完了したプレイと、入力されたコミュニティ名を保存する。

| 置き場所 | 条件 |
| --- | --- |
| Neon Postgres | `DATABASE_URL` があるとき。v0 から公開した本番はこちら |
| `data/party.sqlite` | ローカルで `DATABASE_URL` が空のとき。このファイルは Git に含めない |

| 経路 | 内容 |
| --- | --- |
| `GET /api/rankings` | コミュニティ順位と個人の自己ベスト |
| `POST /api/runs` | 全問を打ち切った記録。問題数も一緒に残す |
| `GET /api/communities` | 選択できるコミュニティ名 |
| `POST /api/communities` | 挑戦開始時にコミュニティ名を残す |
| `GET /api/settings` | いまの問題数 |
| `PUT /api/settings` | 問題数を変える。管理パスワードが要る |
| `GET /api/admin` | パスワードが要るかと、記録・コミュニティの件数 |
| `POST /api/admin/reset` | 記録とコミュニティ名をすべて消す。管理パスワードが要る |

## デプロイ

公開は [v0](https://v0.app) から Vercel へ出す。データベースは Neon。

1. この GitHub リポジトリを v0 のプロジェクトとして開く
2. Project の Settings → Integrations で Neon を作成する。`DATABASE_URL` がプロジェクトに入る
3. Project の Environment Variables に `ADMIN_PASSWORD` を入れる。設定画面のパスワードになる
4. Publish で本番に出す

`DATABASE_URL` が空のまま Vercel 上で記録 API を呼ぶと失敗する。ローカルから同じ Neon を使うときは、接続文字列を `.env.local` に書く。書き方は `.env.example` を見る。
